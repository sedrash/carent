# Carnet de Compétences

Portfolio personnel de Sedra Shalhawi, future ingénieure en cybersécurité et ingénierie informatique.  
Le site présente mon parcours, mes compétences, mes projets académiques et professionnels, ainsi que mes expériences bénévoles.

## Site en ligne

https://sedrash.github.io/carent/

## Contenu du site

- `index.html` : page d'accueil et portrait professionnel.
- `competences.html` : compétences techniques, transversales et comportementales.
- `projets.html` : projets internationaux, projets en entreprise, projets académiques et projets cyber.
- `experience.html` : stages, jobs étudiants et expériences professionnelles.
- `benevolat.html` : engagements bénévoles et valeurs développées.

## Fonctionnalités

- Interface responsive adaptée aux écrans mobiles et desktop.
- Navigation entre les différentes pages du portfolio.
- Animations d'apparition au défilement.
- Sélecteur de langue local : français, anglais, allemand et arabe.
- Mise en avant des projets avec liens GitHub.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Lancer le projet en local

Le site est statique. Il suffit d'ouvrir `index.html` dans un navigateur.

Pour éviter certains problèmes de cache ou de chemins, il est aussi possible de lancer un petit serveur local depuis le dossier du projet :

```bash
python3 -m http.server 8000
```

Puis ouvrir :

```text
http://localhost:8000
```
